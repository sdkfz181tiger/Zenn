# 01: Ollamaとは!?

[Ollama](https://ollama.com/)は、ローカル環境で気軽にLLM(Large Language Model)を実行・管理するツールです。

お手持ちのコンピューター(ある程度性能は必要)内で動作する為、トークン消費を気にせずLLMを使う事ができます。
クラウドAPIへデータを送信せず、ローカル環境だけでLLMを実行できます。

更に、[様々なモデル](https://ollama.com/library)を自由に選択することも可能です。
(一度モデルをダウンロードした後は、インターネット接続なしでも利用できます)

![](/images/articles/bb22e00f405626/01.png)

# 02: インストール

インストールはとても簡単です。
下記のコマンドをターミナルで実行します。

```command:インストール
curl -fsSL https://ollama.com/install.sh | sh
```

インストール後、下記のコマンドでバージョンを確認します。

```command:バージョン
ollama --version
```

![](/images/articles/bb22e00f405626/02.png)
***インストールとバージョン確認***

# 03: ターミナルで実行

インストールが終わったら、さっそく動作確認をしてみます。
```gemma3:1b```は、利用するモデルの本体です。

```command:gemma3を起動(モデルの容量は815MB)
ollama run gemma3:1b
```

ここでは、"gemma"の軽量なモデルを選択していますが、
他にも[様々なモデル](https://ollama.com/library)を指定する事が可能です。
一般的には、パラメータ数やモデルサイズが大きいほど高性能ですが、その分メモリ消費や動作速度も大きくなります。(容量は量子化方式によって変わります)

| モデル | 特徴 | 容量 |
| ---- | ---- | ---- |
| gemma3:270m | テキストのみ | 270MB |
| gemma3:1b | テキストのみ | 815MB |
| gemma4:e2b | テキスト&画像 | 7.2GB |
| gemma4:e4b | テキスト&画像 | 9.6GB |
| gemma4:12b | テキスト&画像 | 8.1GB |

立ち上げ後は対話形式で会話を行う事ができます。

![](/images/articles/bb22e00f405626/03.png)
***対話形式で会話***

会話を終了したい時は、次のコマンドを実行します。

```command:会話の終了
/bye
```

# 04: Pythonから実行

Pythonから実行するには、"ollama"ライブラリが必要です。

```command:インストール
pip install ollama
```

```ollama.chat()```を使った、簡単な例は次のとおりです。

```python:main.py
import ollama

# Messages
messages = [
    {"role": "user", "content": "自己紹介してください。"}
]

# Ollama
response = ollama.chat(
    model="gemma3:1b",
    messages=messages)

print("Answer:\n", response.message.content)
```

# 05: メッセージを工夫する

```ollama.chat()```に与える"messages"を工夫すると、
AIが演じるキャラクターを与えたり、会話の前後の流れを維持した上で会話することができます。
(これらのメッセージを積み重ねつつ会話を続けます)

| role | 意味 | 例 |
| ---- | ---- | ---- |
| system | AIが演じるキャラクター | あなたは、偉大な数学者ニュートンです。 |
| user | ユーザーが投げた質問 | あなたは誰? |
| assistant | AIが出した直前の回答 | 私は数学が大好きなイギリスのおっさんです。 |

```python:メッセージの例
# Messages
messages = [
    {"role": "system", "content": "あなたは、有名な数学者ニュートンです。"},
    {"role": "user", "content": "あなたは誰?"},
    {"role": "assistant", "content": "私は数学が大好きなイギリスのおっさんです。"},
    {"role": "user", "content": "円周率って何?"}
]
```

実行結果は次のとおりです。

# 06: 画像認識を実行

"gemma4"は、マルチモーダル(テキスト&画像)に対応しています。
```command:gemma4を起動(モデルの容量は9.6GB)
ollama run gemma4:e4b
```

"messages"に画像を指定すると画像認識をすることができます。

![](/images/articles/bb22e00f405626/cat.png)
***猫の画像***

```python:画像認識の例
# Messages
messages = [
    {"role": "system", "content": "あなたは、有名な数学者ニュートンです。"},
    {"role": "user", 
    "content": "この画像に写っているものは何ですか?",
    "images": ["cat.png"]}
]

# Ollama
response = ollama.chat(
    model="gemma4:e4b",
    messages=messages)

print("Answer:\n", response.message.content)
```

実行結果は次のとおりです。(猫の画像をニュートンが解説)

# 07: 様々なモデルと特徴

Ollamaでは、"gemma"以外にも[様々なモデル](https://ollama.com/search)を利用することが可能です。
代表的なモデルと、その特徴を紹介します。

| モデル | 特徴 | 開発 |
| ---- | ---- | ---- |
| llama | 定番のオープンモデル。多くの派生モデルのベース。 | Meta(アメリカ) |
| gemma | 軽量で扱いやすく、初心者にもおすすめ。 | Google(アメリカ) |
| gpt-oss | 推論性能が高く、ツール利用にも対応。 | OpenAI(アメリカ) |
| phi | 小型モデルでも高性能なのが特徴。 | Microsoft(アメリカ) |
| kimi | 長文処理が得意。日本語を含む多言語性能も高い。 | Moonshot AI(中国) |
| deepseek | プログラミングや数学問題に強い。高性能ながら軽量版も充実。 | DeepSeek(中国) |
| mistral | 高速・軽量で実用性が高い。商用利用もしやすい。 | Mistral AI(フランス) |
