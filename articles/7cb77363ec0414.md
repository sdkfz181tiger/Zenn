# 01: YOLOとは!?

YOLO(You Only Look Once)は物体検知アルゴリズムの総称です。
本記事では[Ultralytics社](https://docs.ultralytics.com/)版の物体検知フレームワークをお借りし、オリジナルの物体検知モデルを構築します。

読み進めるにあたり、1,2の記事を参照されますと、よりスムーズに読み進める事ができると思います。
1, [YOLOでかんたん物体検知入門](https://zenn.dev/sdkfz181tiger/articles/77da5c55ec8d95)
2, [YOLOでかんたん転移学習入門](https://zenn.dev/sdkfz181tiger/articles/32100dc6882faa)
3, [YOLOでかんたんアノテーション入門](https://zenn.dev/sdkfz181tiger/articles/7cb77363ec0414) <- 本記事

# 02: 学習用データを用意する

# 03: LabelStudioのインストールと起動

画像データにアノテーションを行うツールとして、[LabelStudio](https://labelstud.io/)を利用します。

![](/images/articles/7cb77363ec0414/02.png)
*LabelStudio*

このツールはPython3.12で起動する為、専用に仮想環境(venv)を用意して起動します。
(3.14ではエラーになるので注意)
仮想環境の構築については、下記の記事がとても参考になります。

Macの場合:
[MACでpyenvとvenvを使ってPythonの仮想環境を構築するメモ](https://qiita.com/t_koba/items/24e8e704a69ffb84ba0f)
Windowsの場合:
[Windows環境にてpythonのバージョンを指定してvenvを作成する](https://qiita.com/UT_ITDaiku/items/4af9c7a1b9a91b98935f)

仮想環境の準備が整ったら、次のコマンドでLabelStudioをインストールします。

```command: venv
# Macの場合
$ python3 -m pip install label-studio
# Windowsの場合
$ python -m pip install label-studio
```

インストール後、次のコマンドでLabelStudioを起動します。

```command: venv
$ label-studio
# Starting development server at http://0.0.0.0:8080/
```

起動後、ブラウザに``` http://0.0.0.0:8080/ ```を入力しLabelStudioにアクセスします。
初回起動時は、EmailとPasswordが必要になるので各自用意しましょう。

![](/images/articles/7cb77363ec0414/03.png)
*LabelStudio*

# 04: 画像にアノテーションをする

ここからが今回の記事の本題です。
先ほど集めた画像データそれぞれに対し、茶トラが写っている範囲を手動でアノテーション(マーキング)していきます。

## 04-1: 新規プロジェクトを作る

"Create Project"で、新規プロジェクトを作ります。

![](/images/articles/7cb77363ec0414/04.png)

プロジェクト名を決めて、"Save"で保存します。

![](/images/articles/7cb77363ec0414/05.png)

## 04-2: 集めた画像をアップロードする

"Go to import"をクリックします。

![](/images/articles/7cb77363ec0414/06.png)

"Drag and Drop..."のエリアに画像をアップロードします。

![](/images/articles/7cb77363ec0414/07.png)

"Import"をクリックします。

![](/images/articles/7cb77363ec0414/08.png)

## 04-3: ラベルを用意する

"Settings"をクリックします。

![](/images/articles/7cb77363ec0414/09.png)

"Labelling Interface"タブ、"Browse Templates"の順にクリックします。

![](/images/articles/7cb77363ec0414/10.png)

"Object Detection with Bounding Box"を選択します。

![](/images/articles/7cb77363ec0414/11.png)

不要なラベルである、"Airplane"と、"Car"を削除します。
(隠れている場合があるので注意!!)

![](/images/articles/7cb77363ec0414/12.png)

新しく、"OrangeCat"を"Add"で追加し、"Save"をクリックします。
右側の画像下に、"OrangeCat"のラベルが表示されれば成功です。
その後、"MyOrangeCat"タブで画像一覧を表示します。

![](/images/articles/7cb77363ec0414/13.png)

## 04-4: 画像にアノテーションをする

任意の画像を選択します。

![](/images/articles/7cb77363ec0414/14.png)

"OrangeCat"を選択し、茶トラが写っている箇所をアノテーションします。
最後に"Submit"をクリックします。

![](/images/articles/7cb77363ec0414/15.png)

この作業を、全ての画像で行います。
(地道な作業ですが、モデルの精度を左右する重要な工程です)

# 05: YOLO形式でエクスポート

ラベリングが終了した後、学習データを"YOLO形式"で出力します。

"Export"ボタンをクリックします。

![](/images/articles/7cb77363ec0414/16.png)

"YOLO with Images"を選択します。

![](/images/articles/7cb77363ec0414/17.png)

"Export"ボタンをクリックすると、ダウンロードが開始されます。

![](/images/articles/7cb77363ec0414/18.png)

出力された圧縮ファイルの中身は次の様なフォルダ構成になっています。
imagesフォルダには、アノテーション対象の画像が、
labelsフォルダのxxx.txtファイルには、アノテーション情報(マーキングした座標等)が記述されています。
例えば、labelsフォルダ内のtxtファイルには次のような値が記録されています。
```text
0 0.512 0.438 0.321 0.287
```
それぞれ、クラスID、中心X座標、中心Y座標、幅、高さになります。

```command: 出力された圧縮ファイルの中身
./project-10-at-...
   ├── classes.txt
   ├── images
   │    ├── xxx.jpg
   │    └── ...
   ├── labels
   │    ├── xxx.txt
   │    └── ...
   └── notes.json
```

# 06: データを分割する

先ほどダウンロードした出力データを、学習用と検証用に分割します。
(手動です!!)

## 06-1: ファイルを配置

新たに"my_dataset"フォルダを作り、次の様にファイルを配置します。
"train"は学習用、"val"は検証用のデータを格納します。
(学習用8 : 検証用2の割合で分割するのがセオリーです)

```text: my_dataset
./my_dataset
   ├── dataset.yaml <- この後に解説します
   ├── images
   │    ├── train
   │    │     ├── xxx.jpg
   │    │     └── ...
   │    └── val
   │          ├── xxx.jpg
   │          └── ...
   └── labels
        ├── train
        │     ├── xxx.txt
        │     └── ...
        └── val
              ├── xxx.txt
              └── ...   
```

## 06-2: YAMLファイルを配置

配置したYAMLファイルには以下の様に記述します。
(pathについては、実行環境によって変わる場合があるので注意)

```yaml: dataset.yaml
path: ./my_dataset

train: images/train
val: images/val

names:
  0: OrangeCat
```

# 07: 学習を実行する

最後に、全体のフォルダ構成を確認します。

```text: my_dataset
./Desktop
   └── yourproject
        ├── main.py <- 実行元スクリプト
        └── my_dataset
             ├── dataset.yaml
             ├── images
             └── labels  
```

この場合、``` main.py ```の処理は次の様になります。
最初は5エポック程度で様子を見てから、10,20と上げながらテストすると良いです。

```python: main.py(抜粋)
# Model(ベースになるモデル)
model = YOLO("yolo26n.pt")

# Train
# 学習(my_datasetデータセットを利用)
# 最初は5エポックで様子を見る...
results = model.train(
    data="./my_dataset/dataset.yaml",
    device="cpu",
    epochs=5, 
    imgsz=640)
```

この先に続く、学習モデルの検証や推論については、[YOLOでかんたん転移学習入門](https://zenn.dev/sdkfz181tiger/articles/32100dc6882faa)を参考に進めることが可能です。
