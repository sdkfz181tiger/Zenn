# Gemini 3.8 Flash TTSではじめるテキスト読み上げ生成

今回は、"[Gemini3.8-Flash-TTS](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-text-to-speech/)"を使ってテキスト読み上げ生成を試してみます。

本モデルでは、130以上の言語がサポートされ、音声として30種類の事前構築済みセットがあらかじめ用意されています。

単一話者の読み上げだけでなく、複数人での対話の再現や、感情・表現スタイルの細かな指定が可能です。


# 2種類のモデルとその特徴

TTSでは主に2種類のモデルが用意されています。
ここでは、`gemini-3.8-flash-lite-tts`を使って読み上げ生成を行います。

| モデル名 | 強み |
| ---- | ---- |
| `gemini-3.8-flash-tts`| 音声の忠実度、演技のニュアンス、方言のカバー率を最大化 |
| `gemini-3.8-flash-lite-tts` | 高スループット、低レイテンシ、費用対効果 |

# 単一話者によるテキスト読み上げ

単一話者でのテキスト読み上げのサンプルコードは下記の通りです。

`genai.Client()`では、先ほど取得したAPI Keyを指定します。

`client.interactions.create()`には、簡単に次の様にデータを指定します。

| パラメータ | 意味 |
| ---- | ---- |
| input->content->text| 読み上げるテキスト |
| input->annotations->style | 発話スタイル("悲しく、辛い、絶望的に"など日本語で指定可能) |
| generation_config->speech_config->voice | 話者の声(ここでは、"Kore"を指定) |

読み上げるテキストに対し、以下のインラインタグで"息継ぎ"等の表現を入れることができます。
例: `お久しぶりです、シャア少佐。<cough> あ、いや、今は大佐でいらっしゃいましたな`

| インラインタグ | 意味 |
| ---- | ---- |
| <cough>| 咳払い |
| <breath> | 息継ぎ |
| <sigh> | ため息 |
| <short pause> | 小さい間 |

話者の声色については、[音声オプション](https://ai.google.dev/gemini-api/docs/speech-generation?hl=ja#voices)を参考にしてください。

```python:main.py
import base64
from google import genai

def main():
    print("main!!")

    # Client
    # 環境変数 GEMINI_API_KEY が設定されている場合は引数を省略できます
    client = genai.Client(api_key="作成したAPI Key")

    interaction = client.interactions.create(
        model="gemini-3.8-flash-lite-tts",
        input=[{
            "type": "user_input",
            "content": [{
                "type": "text",
                "text": "燃え上がれ、燃え上がれ、燃え上がれガンダム!!",
                "annotations": [{
                    "type": "speech_metadata",
                    "style": "悲しく、辛い、絶望的に",
                }],
            }],
        }],
        response_format={"type": "audio"},
        generation_config={
            "speech_config": [
                {"voice": "Kore"},
            ]
        },
    )

    with open("out.wav", "wb") as f:
        f.write(base64.b64decode(interaction.output_audio.data))


if __name__ == "__main__":
    main()
```

実行すると、音声ファイルとして"out.wav"ファイルが生成されます。

# 複数話者での会話

次は、複数人での会話をテキスト読み上げするサンプルコードです。

下記の点にだけ注意すれば、先ほどのサンプルと同じ様に使うことができます。

| パラメータ | 意味 |
| ---- | ---- |
| annotations->speaker| 話者のID(ここでは"Doren"と"Char") |
| speech_config->mode | conversational |
| speech_config->speakers->speaker | 話者のIDと合わせ、voiceを指定 |

```python:main.py
import base64
from google import genai

def main():
    print("main!!")

    # Client
    # 環境変数 GEMINI_API_KEY が設定されている場合は引数を省略できます
    client = genai.Client(api_key="作成したAPI Key")

    interaction = client.interactions.create(
        model="gemini-3.8-flash-lite-tts",
        input=[{
            "type": "user_input",
            "content": [
                {
                    "type": "text",
                    "text": "お久しぶりです、シャア少佐。あ、いや、今は大佐でいらっしゃいましたな",
                    "annotations": [{
                        "type": "speech_metadata",
                        "speaker": "Doren",
                        "style": "恐縮しながら",
                    }],
                },{
                    "type": "text",
                    "text": "相変わらずだな、ドレン",
                    "annotations": [{
                        "type": "speech_metadata",
                        "speaker": "Char",
                        "style": "落ち着き、冷静に",
                    }],
                },{
                    "type": "text",
                    "text": "はっ!!",
                    "annotations": [{
                        "type": "speech_metadata",
                        "speaker": "Doren",
                        "style": "恐縮しながら",
                    }],
                },{
                    "type": "text",
                    "text": "木馬を追っている。ちょうどお前の艦隊の位置なら木馬の頭を押さえられる",
                    "annotations": [{
                        "type": "speech_metadata",
                        "speaker": "Char",
                        "style": "落ち着き、冷静に",
                    }],
                },{
                    "type": "text",
                    "text": "ご縁がありますな、木馬とは。わかりました。追いつけますか？",
                    "annotations": [{
                        "type": "speech_metadata",
                        "speaker": "Doren",
                        "style": "恐縮しながら",
                    }],
                },{
                    "type": "text",
                    "text": "ドレン、私を誰だと思っているのだ？",
                    "annotations": [{
                        "type": "speech_metadata",
                        "speaker": "Char",
                        "style": "落ち着き、冷静に",
                    }],
                },{
                    "type": "text",
                    "text": "申し訳ありません、大佐",
                    "annotations": [{
                        "type": "speech_metadata",
                        "speaker": "Doren",
                        "style": "恐縮しながら",
                    }],
                },
            ],
        }],
        response_format={"type": "audio"},
        generation_config={
            "speech_config": {
                "mode": "conversational",
                "speakers": [
                    {"speaker": "Doren", "voice": "Puck"},
                    {"speaker": "Char", "voice": "Kore"},
                ],
            }
        },
    )

    with open("out.wav", "wb") as f:
        f.write(base64.b64decode(interaction.output_audio.data))


if __name__ == "__main__":
    main()
```

実行すると、音声ファイルとして"out.wav"ファイルが生成されます。
