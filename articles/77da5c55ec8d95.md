# 01: YOLOとは!?

YOLO(You Only Look Once)は物体検知アルゴリズムの総称です。
本記事では[Ultralytics社](https://docs.ultralytics.com/)版の物体検知フレームワークをお借りします。
実装方法もシンプルなので、初学者さんに特にオススメです。

![](/images/articles/77da5c55ec8d95/banner_01.png)

YOLOは、画像や映像に映った特定の物体検知だけでなく、
[移動する物体の追跡(トラッキング)](https://docs.ultralytics.com/modes/track#why-choose-ultralytics-yolo-for-object-tracking)、[姿勢の推論(ポーズ)](https://docs.ultralytics.com/tasks/pose)、[物体の集計(オブジェクトカウンティング)](https://docs.ultralytics.com/guides/region-counting)、[物体の境界判別(セグメンテーション)](https://docs.ultralytics.com/tasks/segment)、など、様々な物体検知に対応しています。
追加で独自データを加える事で、独自の分類器をカスタムする事も可能です。

下記のコマンドでYOLOをインストールできます。(はじめの一歩!!)

```command:インストール
pip install ultralytics
```

# 02:物体の追跡(トラッキング)

動いている物体を継続して追跡しながら検知します。

## 02-1: モデルの読み込みと推論

初めにモデルをロードします。
この部分で読み込むモデルは[複数種類](https://docs.ultralytics.com/models/yolo26#supported-tasks-and-modes)ありますが、必要に応じて使い分けると良いでしょう。
```yolo26n.pt < yolo26s.pt < yolo26m.pt < yolo26l.pt < yolo26x.pt```
の順に軽いモデルになります。(右のものほど重く、性能が高いモデルです)

ここでは、最も軽い"yolo26n.pt"を利用します。
(モデルはコード実行時、自動的にダウンロードされます)

```python:main.py(抜粋)
# モデルをロード
model = YOLO("yolo26n.pt")
```

後は、物体検知のタイミングで```model.track()```を実行するだけです。

```python:main.py(抜粋)
# トラッキング
frame_tracked = model.track(
    frame, persist=True, verbose=False)[0].plot()
```

物体検知に成功すると、検知対象のIDと、バウンディングボックスが描画されます。

![](/images/articles/77da5c55ec8d95/02_01.gif)

物体検知に利用する動画は、[pexels](https://www.pexels.com/ja-jp/)等のフリー素材サイトから借りると良いでしょう。

```python:main.py
# coding: utf-8

import cv2, os
import utilities.utility as utility
from moviepy import VideoFileClip, AudioFileClip, AudioArrayClip
from pathlib import Path
from PIL import Image
from ultralytics import YOLO, solutions

def main():
    """ Main """
    print("main")

    # Prediction
    start_prediction("../assets/hoge.mp4")


def start_prediction(path_file):
    print("start_prediction:", path_file)

    path = Path(path_file)
    path_from = path
    path_to   = path.name
    path_comp = Path(f"{path.stem}_comp{path.suffix}")
    
    # Video(From)
    cap_from   = cv2.VideoCapture(path_from)
    w          = int(cap_from.get(cv2.CAP_PROP_FRAME_WIDTH))# Width
    h          = int(cap_from.get(cv2.CAP_PROP_FRAME_HEIGHT))# Height
    count      = int(cap_from.get(cv2.CAP_PROP_FRAME_COUNT))# Count
    fps        = int(cap_from.get(cv2.CAP_PROP_FPS))# Fps
    resolution = (w, h)
    print("Video W:%d H:%d COUNT:%d FPS:%d" % (w, h, count, fps))

    # Video(To)
    fourcc = cv2.VideoWriter_fourcc(*"mp4v")
    cap_to = cv2.VideoWriter(
        path_to, fourcc, fps, resolution)

    # Model
    model = YOLO("yolo26n.pt")

    # Render
    for n in range(count):
        ret, frame = cap_from.read()# Read
        if ret==False: break

        # Track
        frame_tracked = model.track(
            frame, persist=True, verbose=False)[0].plot()

        # Grid
        utility.draw_grid(w, h, frame_tracked, (255, 255, 255), 1)
        cap_to.write(frame_tracked)

    # Release
    cap_from.release()
    cap_to.release()
    
    # Audio
    #utility.write_audio(path_from, path_to, path_comp)


if __name__ == "__main__":
    main()
```

```python:utilities/utility.py
import cv2, os
from moviepy import VideoFileClip, AudioFileClip, AudioArrayClip
from pathlib import Path
from PIL import Image
from ultralytics import YOLO, solutions


def draw_grid(w, h, frame, l_color, l_width,
    f_scale=1.0, f_color=(255, 255, 255), f_thickness=4):
    g_size = int(w / 20)
    rows = int(h / g_size)
    cols = int(w / g_size)
    for r in range(1, rows):
        y = r * g_size
        cv2.line(frame, (0, y), (w, y), l_color, l_width)
        cv2.putText(frame, str(y), (10, y), 
            cv2.FONT_HERSHEY_SIMPLEX, 
            f_scale, f_color, f_thickness)
    for c in range(1, cols):
        x = c * g_size
        cv2.line(frame, (x, 0), (x, h), l_color, l_width)
        cv2.putText(frame, str(x), (x, h-10), 
            cv2.FONT_HERSHEY_SIMPLEX, 
            f_scale, f_color, f_thickness)

    clip_from = VideoFileClip(path_from).subclipped()
    clip_to = VideoFileClip(path_to).subclipped()
    clip_comp = clip_to.with_audio(clip_from.audio)
    clip_comp.write_videofile(path_comp, codec="libx264", audio_codec="aac")
```

# 04:物体の集計(オブジェクトカウンタ)

特定の線を横切った自動車などを集計するオブジェクトカウンタです。

TODO: 結果のgif(オブジェクトカウンタ)

## 04-1: モデルの読み込みと推論

オブジェクトカウンタのモデルは、
```solutions.ObjectCouner()```クラスで用意します。
主な引数の意味は、それぞれ下記のとおりです。

| 引数 | 意味 |
| ---- | ---- |
| model | モデル名 |
| region | カウントする境界線 |
| classes | 検知対象の物体 |

```region```には、検知対象をカウントする境界線のx,y座標をリストで指定します。
このラインを横切る物体があると、自動集計します。

```classes```には、[YOLOが定義(COCO)](https://docs.ultralytics.com/datasets/segment/coco#dataset-yaml)した検知対象の物体をリストで指定します。
今回の検知対象は、自動車、バイク、バス、トラックなので、2,3,5,7を指定しています。

```python:main.py(抜粋)
# Model
counter = solutions.ObjectCounter(
    model="yolo26n.pt", show=False,
    region=[(0, h // 2), (w, h // 2)],
    classes=[2, 3, 5, 7],
    line_width=4)
```

物体検知の処理は次のとおりです。

```python:main.py(抜粋)
# Counter
frame_counter = counter(frame).plot_im
```

# 05: Webカメラでリアルタイム検知

これまでは、動画ファイル(mp4)を対象に検知を行っていましたが、
Webカメラを対象にする事で、リアルタイム推論を行う事が可能です。

![](/images/articles/77da5c55ec8d95/05_01.gif)

完成コードは次のとおりです。

:::details 完成コード
```python:main.py
# coding: utf-8

import cv2, os
import utilities.utility as utility
from flask import Flask, render_template, Response
from moviepy import VideoFileClip, AudioFileClip, AudioArrayClip
from pathlib import Path
from PIL import Image
from ultralytics import YOLO, solutions

# Flask
app = Flask(__name__)

# WebCam
# Linux: $ ls /dev/video*
# Mac: $ system_profiler SPCameraDataType
camera = cv2.VideoCapture(0, cv2.CAP_AVFOUNDATION)
w = int(camera.get(cv2.CAP_PROP_FRAME_WIDTH))
h = int(camera.get(cv2.CAP_PROP_FRAME_HEIGHT))

# Model
model = YOLO("yolo26n.pt")


def main():
    """ Main """
    print("main")

    # Server
    app.run(host="0.0.0.0", port=5000, debug=True)


def generate_frames():
    global w, h, model

    while True:
        # Camera
        success, frame = camera.read()
        if not success:
            break

        # Track
        frame_tracked = model.track(
            frame, persist=True, verbose=False)[0].plot()

        # Grid
        utility.draw_grid(w, h, frame_tracked, (255, 255, 255), 1)

        # Frame -> JPG
        ret, buffer = cv2.imencode(".jpg", frame_tracked)

        # JPG -> MIME
        yield(b"--frame\r\n"
            b"Content-Type: image/jpeg\r\n\r\n" + buffer.tobytes() + b"\r\n")


# Flask
@app.route("/")
def index():
    # Rendering
    return render_template("index.html")


@app.route("/video_streaming")
def video_streaming():
    # Streaming
    return Response(generate_frames(), 
        mimetype="multipart/x-mixed-replace; boundary=frame")


if __name__ == "__main__":
    main()
```
