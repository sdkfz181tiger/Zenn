# 01: MCPとは!?

MCP(Model Context Protocol)とは、LLMと様々なAPIを連携させる規約です。
MCPを利用する事で、LLMに様々な機能を与える事ができます。

今回は、[FastMCP](https://gofastmcp.com/getting-started/quickstart)でMCPサーバーを立ち上げ、Ollamaに利用させるまでの手順を解説します。
FastMCPはPythonでMCPサーバーを簡単に作成するためのライブラリです。

Ollamaについては、[OllamaではじめるローカルLLM入門](https://zenn.dev/sdkfz181tiger/articles/bb22e00f405626)をご参照ください。

# 03: MCPサーバーを立ち上げる

```FastMCP()```でMCPサーバーを用意します。
後に続く、```mcp.run()```で実際にサーバーが立ち上がります。
今回は、```http://127.0.0.1:8080```にサーバーを用意します。

次に、与えられた数値を加算した結果を返す```add()```ツールを作ります。
(MCPで用意する機能は関数ではなく、"ツール"と呼びます)

用意するツールに```@mcp.tool()```デコレーターを記述しておきます。
そして、docstringにこのツールの説明文を記述する事を忘れないでください。
LLMは、この説明文を解釈し、必要と判断した時に利用します。

ここでは、"add, double, triple"の3つのツールを用意しています。
(docstringの記述を忘れずに!!)

```python:mcp_server.py
from fastmcp import FastMCP

# MCP
mcp = FastMCP("MyFirstMCP")

def main():
    print("main!!")

    # Run
    mcp.run(transport="http", host="127.0.0.1", port=8080)

@mcp.tool()
def add(a: int, b: int)->int:
    """与えられた2つの整数の合計を返す"""
    print("add:", a, b)
    return a + b

@mcp.tool()
def double(a: int)->int:
    """与えられた整数を2倍して返す"""
    print("double:", a)
    return a * 2

@mcp.tool()
def triple(a: int)->int:
    """与えられた整数を3倍して返す"""
    print("triple:", a)
    return a * 3

if __name__ == "__main__":
    main()
```

# 04: MCPサーバーのツールを確認する(クライアント)

クライアントから、MCPサーバーで用意したツールの確認と実行テストをします。

```Client("http://127.0.0.1:8080/mcp")```の部分でクライアントを立ち上げ、MCPサーバーを指定します。

その後、```client.list_tools()```を実行することで、
MCPサーバーに用意された3つのツール、"add, double, triple"を確認することができます。

最後に、```client.call_tool("add", {"a": 1, "b": 99})```の部分で"add"ツールの実行テストを行います。
結果が"100"と出れば成功です。

```python:mcp_client.py
from fastmcp import Client
import asyncio
import json

async def main():
    print("main!!")

    # Messages
    messages = []

    # MCP Client
    client = Client("http://127.0.0.1:8080/mcp")
    async with client:

        # ツール一覧を取得
        text = ""
        tools = await client.list_tools()
        for tool in tools:
            text += f"- ツール名: {tool.name}\n"
            text += f"  - 説明: {tool.description}\n"
            text += f"  - 引数: {json.dumps(tool.inputSchema['properties'])}\n"
            if tool.outputSchema:
                text += f"  - 出力: {json.dumps(tool.outputSchema['properties'])}\n"
        print("=== 利用可能ツール ===")
        print(text)

        # 実行テスト("add"ツールで1+99を計算させる)
        result = await client.call_tool("add", {"a": 1, "b": 99})
        print("Result:", result.data)

if __name__ == "__main__":
    asyncio.run(main())
```

# 05: MCPサーバーを利用する(Ollama)

OllamaとMCPサーバーを接続します。

あらかじめ、ローカル環境でOllamaを立ち上げておきます。
詳細については、[OllamaではじめるローカルLLM入門](https://zenn.dev/sdkfz181tiger/articles/bb22e00f405626)をご参照ください。

```command:Ollama
ollama run gemma4:e4b
```

はじめに、最初のメッセージ"system"の文面を用意します。
この中で、AI自身がツールを必要と判断した場合、```{{ "tool": "ツール名", "args": {{"引数": "値", "引数": "値"}} }}```のフォーマットで要求をするよう指示を与えます。(フォーマットは自分で決める必要があります)

```python:mcp_client.py(抜粋)
PROMPT_SYSTEM = """
あなたはAIエージェントです。
あなたは次のツールを使うことができます。
{tools}
なお、上記のツールを使う場合は、
以下のフォーマットで文字列を組み立て、文章の末尾に追加してください。
===
{{ "tool": "ツール名", "args": {{"引数": "値", "引数": "値"}} }}
===
"""
```

加えて、"user"のメッセージを追加し、```ollama.chat()```を実行します。

```python:mcp_client.py(抜粋)
# メッセージ
content = PROMPT_SYSTEM.format(tools=", ".join(tool.name for tool in tools))
messages.append({"role": "system", "content": content})
messages.append({"role": "user", "content": "3と8の合計を計算して?"})

# Ollama(最初のチャット)
response = ollama.chat(
    model="gemma4:e4b",
    messages=messages)

# レスポンス
res = response.message.content
print("Ollama(最初のチャット):", res)
```

次に、Ollamaから受け取ったメッセージを解析し、当該フォーマットに従った文字列が見つかった場合、```client.call_tool()```でツールを実際に実行します。

```python:mcp_client.py(抜粋)

# ツールの利用判定
if res.startswith("===") and res.endswith("==="):
    res   = res[3:-3].strip()
    j_obj = json.loads(res)
    tool  = j_obj.get("tool", "")
    args  = j_obj.get("args", {})
    print("client.call_tool():", tool, args)
    result = await client.call_tool(tool, args)
    print("Result:", result.data)
```

最後に、ツールから受け取った結果をOllamaに返します。
ここで最終的にOllamaがツールの利用をした上で最終回答を行います。

```python:mcp_client.py(抜粋)
# メッセージ
messages.append({"role": "assistant", "content": res})
messages.append({"role": "tool", "content": str(result.data)})

# Ollama(ツールの結果を加味してチャット)
response = ollama.chat(
    model="gemma4:e4b",
    messages=messages)

# レスポンス
res = response.message.content
print("Ollama(ツールの結果を加味してチャット):", res)
```

# 06: 複数のAPIを組み合わせて再起的に利用させる

Ollamaに複数のツールを利用させ、その結果を出力させるサンプルを用意しました。
(追記: 2026年09月28日)

まず、MCPサーバー側に下記の様に2つのツールを備えておきます。

| ツール名 | 意味 |
| ---- | ---- |
| get_area_code | 都道府県名からエリアコードを取得するツール |
| get_forecast | エリアコードから、天気予報を取得するツール |

:::details 完成コード(MCPサーバー)
```python: mcp_server.py
from fastmcp import FastMCP
import json
import re
import requests

# URL
URL_AREA_CODE = "https://www.jma.go.jp/bosai/common/const/area.json"
URL_FORECAST = "https://www.jma.go.jp/bosai/forecast/data/overview_forecast/"

# MCP
mcp = FastMCP("MyForecastMCP")

def main():
    print("main!!")

    # Run
    mcp.run(
        transport="streamable-http",
        host="127.0.0.1", 
        port=8080)


@mcp.tool()
def get_area_code(area_name: str)->str | None:
    """
    日本の都道府県名に対応するエリアコードを取得します。

    引数:
        area_name: 「愛知県」や「東京」などの日本の都道府県名。

    戻り値:
        エリアコード（文字列）。
        該当する都道府県が見つからない場合は None を返します。
    """
    res = requests.get(URL_AREA_CODE, timeout=5)
    offices = res.json()["offices"]
    for key, office in offices.items():
        if office["name"] == area_name:
            return str(key)
    return None


@mcp.tool()
def get_forecast(area_code: str)->str:
    """
    地域コードを使用して、日本の特定の地域の天気予報を取得します。

    引数:
        area_code: 予報対象地域の地域コード。
              `get_area_code()` が返す地域コード（例: "070000"、"210000"）を指定してください。

    戻り値:
        指定された地域の天気予報。
    """
    url = URL_FORECAST + area_code + ".json"
    res = requests.get(url, timeout=5)
    text = res.json()["targetArea"] + "の、天気予報です。" + res.json()["text"]
    return re.sub(r'\s+', '', text)


if __name__ == "__main__":
    main()
```
:::


次に、クライアント側からOllamaを実行します。
ここでは、あらかじめ`max_steps`でループ回数に制限をかけてあります。
ツールの実行後は、その結果を利用して再び実行する流れになっています。


```python: mcp_client.py(抜粋)
# Agent loop
max_steps = 8
for step in range(max_steps):

    # Ollama
    response = ollama.chat(
        model=OLLAMA_MODEL,
        messages=messages)

    # Responce
    content = response.message.content.strip()
    print(f"Ollama[{step}]: {content}")

    # Messages
    messages.append({
        "role": "assistant",
        "content": content})

    # Tool chain
    json_obj = parse_json(ollama_tools, content) # Parse
    if json_obj is not None:
        print(json_obj)

        # Tool
        result = await client.call_tool(
            json_obj["tool"], json_obj["args"]
        )
        print(f"Result: {result.data}")

        # Message
        messages.append({
            "role": "tool",
            "content": (
                f"Tool: {json_obj["tool"]}\n"
                f"Result: {result.data}\n"
            )
        })
        messages.append({
            "role": "user",
            "content": (
                f"実行結果は{result.data}です\n"
                f"この結果を利用して、元のユーザーの依頼を続けてください"
            )
        })

        continue
    else:
        print(f"回答: {content}")
        break
```

:::details 完成コード(クライアント)
```python: mcp_client.py
from fastmcp import Client
import asyncio
import json
import ollama

MCP_URL = "http://127.0.0.1:8080/mcp"
OLLAMA_MODEL = "gemma4:e2b"

PROMPT_SYSTEM = """
あなたはAIエージェントです。
あなたは以下のツールを使用できます。

{tools}

ツールを使う場合は、下記のフォーマットで文字列を出力してください。

{{ "tool": "ツール名", "args": {{"引数名": "値", "引数名": "値"}} }}
"""


async def main():

    print("=== Agent Start ===")

    messages = []

    client = Client(MCP_URL)

    async with client:

        # MCP Tools
        mcp_tools = await client.list_tools()
        ollama_tools = mcp_tools_to_ollama_tools(mcp_tools)

        content = PROMPT_SYSTEM.format(tools=ollama_tools)
        messages.append({"role": "system", "content": content})
        messages.append({"role": "user", "content": "岐阜県の天気を教えて"})

        # Agent loop
        max_steps = 8
        for step in range(max_steps):

            # Ollama
            response = ollama.chat(
                model=OLLAMA_MODEL,
                messages=messages)

            # Responce
            content = response.message.content.strip()
            print(f"Ollama[{step}]: {content}")

            # Messages
            messages.append({
                "role": "assistant",
                "content": content})

            # Tool chain
            json_obj = parse_json(ollama_tools, content) # Parse
            if json_obj is not None:
                print(json_obj)

                # Tool
                result = await client.call_tool(
                    json_obj["tool"], json_obj["args"]
                )
                print(f"Result: {result.data}")

                # Message
                messages.append({
                    "role": "tool",
                    "content": (
                        f"Tool: {json_obj["tool"]}\n"
                        f"Result: {result.data}\n"
                    )
                })
                messages.append({
                    "role": "user",
                    "content": (
                        f"The tool execution result is {result.data}\n"
                        f"Please proceed with the original user's request using this result"
                    )
                })

                continue
            else:
                print(f"回答: {content}")
                break


if __name__ == "__main__":
    asyncio.run(main())


def mcp_tools_to_ollama_tools(mcp_tools):
    tools = []

    for tool in mcp_tools:
        tools.append({
            "type": "function",
            "function": {
                "name": tool.name,
                "description": tool.description,
                "input_schema": tool.input_schema,
            }
        })

    return tools


def parse_json(ollama_tools, content):

    try:
        json_obj = json.loads(content)
        for tool in ollama_tools:
            if json_obj["tool"] == tool["function"]["name"]:
                return json_obj
    except json.JSONDecodeError as e:
        return None
    return None
```
