# 01: YOLOで転移学習をする

YOLO(You Only Look Once)は物体検知アルゴリズムの総称です。
今回は、独自の物体を検知する専用モデルを構築するまでの流れを試します。
本記事では[Ultralytics社](https://docs.ultralytics.com/)版の物体検知フレームワークをお借りします。

# 02: 全体の流れ

独自のモデルを構築するまでの流れは次のとおりです。

1, フレームワークのインストール
2, データの準備(COCO8) <- 事前に準備は不要です
3, 学習
4, 評価
5, 推論

# 03: フレームワークのインストール

YOLO(Ultralytics)は、次のコマンドでインストールします。

```command:インストール
pip install ultralytics
```

本フレームワークの簡単な使い方については、[前回の記事](https://zenn.dev/sdkfz181tiger/articles/77da5c55ec8d95)をご参照くださいませ。

# 04: データの準備

学習用のデータは、YOLO(Ultralytics)で用意された"COCO8"を利用します。

これは、学習用画像4枚、検証用画像4枚の合計8枚の小さなデータセットであり、
学習の流れ、検証の方法、推論の確認までを体験するのに最適です。

![](/images/articles/32100dc6882faa/01.png)
*COCO8データセット*

しかも、"COCO8"データセットは、学習の初回実行時に自動ダウンロードされる為、
あらかじめダウンロードしておく必要はありません。(かんたんですね!!)

実際には独自データセット(yaml)を指定することで
オリジナル物体検知モデルを作成できます。

# 05: 学習

学習を始めるにあたり、ベースとなるモデルとして、"yolo26n.pt"を選択します。
転移学習では、あらかじめ学習済みのモデルを利用し、それをベースに追加学習を行います。
(モデルデータも自動でダウンロードされます!!)

次に、``` model.train() ```で学習を開始します。
引数の意味はそれぞれ次のとおりです。

| 引数 | 意味 |
| ---- | ---- |
| data | 学習用のデータセット(COCO8) |
| epochs | エポック数(学習回数) |
| imgsz | 画像のサイズ(640x640) |

```python:main.py(抜粋)
# Model(ベースになるモデル)
model = YOLO("yolo26n.pt")

# Train
# 学習(COCO8データセットを利用)
results = model.train(
    data="coco8.yaml", 
    epochs=100, 
    imgsz=640)
```

学習を実行すると、"runs"フォルダが自動生成されます。
その中にある、"best.pt"が、転移学習後のモデルになります。

```command:フォルダ構成
./runs
   ├── detect
   ├── train <- COCO8データセット
   ├── weights
   │    ├── best.pt <- 学習中に最も良い評価結果を出したモデル
   │    └── last.pt <- 最終エポック終了時点のモデル
   ├── results.csv
   ├── results.png
   └── ...
```

# 06: 検証

学習後のモデル"best.pt"を評価します。
```model.val()```を実行するだけです。
実行結果として、様々なmAPという適合率を得る事ができます。

mAP50-95とは、
IoUの閾値を0.50〜0.95まで変化させながら計算した平均適合率の事で、
物体検出モデルの性能を評価する代表的な指標です。

```python:main.py(抜粋)
# Model(学習中に最も良い評価結果を出したモデル)
model = YOLO("./runs/detect/train/weights/best.pt")

# Validate
metrics = model.val()

# 0.5から0.95までの複数のIoU閾値における平均適合率
print(metrics.box.map)   # mAP50-95
print(metrics.box.map50) # mAP50
print(metrics.box.map75) # mAP75
print(metrics.box.maps)  # 各クラス別の適合率
print(metrics.box.mp)    # Precision
print(metrics.box.mr)    # Recall
```

*実行結果*

今回の結果は次のとおりになりました。
(値が1.0に近いほど良い成績です)

| mAP50-95 | 0.7145457218237519 |
| mAP50 | 0.8868083900226758 |
| mAP75 | 0.8195580808080809 |

# 07: 推論

検証後のモデルを実際に使ってみます。
``` model.predict() ```の引数、"save=True"とする事で、実行結果を画像出力します。

```python:main.py(抜粋)
# Model
model = YOLO("./runs/detect/train/weights/best.pt")

# Predict
results = model.predict(
    source="https://ultralytics.com/images/bus.jpg",
    save=True)
print(results)
```

```python:main.py
from ultralytics import YOLO, solutions

def main():
    """ Main """
    print("main")

    train()    # 学習をテスト
    #validate() # 検証をテスト <- 試す時にコメントアウト
    #predict()  # 推論をテスト <- 試す時にコメントアウト


def train():
    """ 学習 """

    # Model(ベースになるモデル)
    model = YOLO("yolo26n.pt")

    # Train
    # 学習(COCO8データセットを利用)
    results = model.train(
        data="coco8.yaml", 
        epochs=100, 
        imgsz=640)


def validate():
    """ 検証 """

    # Model
    model = YOLO("./runs/detect/train/weights/best.pt") # 学習中に最も良い評価結果を出したモデル
    #model = YOLO("./runs/detect/train/weights/last.pt") # 最終エポック終了時点のモデル
    
    # Validate
    metrics = model.val()

    # 0.5から0.95までの複数のIoU閾値における平均適合率
    print(metrics.box.map)   # mAP50-95
    print(metrics.box.map50) # mAP50
    print(metrics.box.map75) # mAP75
    print(metrics.box.maps)  # 各クラス別の適合率


def predict():
    """ 推論 """

    # Model
    model = YOLO("./runs/detect/train/weights/best.pt")

    # Predict
    # ./runs/detect/predict/bus.jpg
    results = model.predict(
        source="https://ultralytics.com/images/bus.jpg",
        save=True)
    print(results)


if __name__ == "__main__":
    main()
```
